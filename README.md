## 运行
纯 HTML/CSS/JavaScript，无构建、无第三方前端依赖。下载整个仓库并解压后双击 `dist/index.html`；也可在 `dist` 下启动静态服务器。需联网才能上传/读取老师后台，实验本身可以离线运行。

参与者先同意匿名收数，再练习、正式作答；两个实验顺序按随机编号分配，仍允许自行选择。更换参与者时在数据页点“换一位被试”。不要输入真实姓名或学号。建议用电脑、固定窗口大小和输入方式。

旧链接参数 `demo=1` 和 `quick=1` 已停用：均运行完整流程并上传。`test=1` 仅标记联调来源，同样真实上传，使用独立 test_ 实验名称。

## 数据与接口
每轮练习、正式阶段结束或主动退出时，将已有记录调用一次 `POST /api/hw2/submit`，正式完整记录的experiment分别为 `visual_search_v1`、`graphical_estimation_v1`；练习为 `practice_search_v1`、`practice_graph_v1`；中断为 `partial_任务_阶段_v1`。payload包含 project、participant、experiment、condition、trials、meta；所有试次字段为标量。

trials保留条件、计划试次、实际试次、反应、rt（ms）、correct、valid、invalid_reason、timeout、匿名编号、session、protocol、时间、窗口尺寸。练习也上传，practice=1；失焦等无效呈现全部保留并补做。中断记录phase_complete=0，正常完成为1。图形误差单位为百分点。

下载密钥只由作者在老师后台保管，不应写入仓库。老师接口允许知道项目码的人读取匿名数据，已在知情同意页说明。每次作答都持久化本机备份，练习完成、正式完成、主动退出后自动上传。异常关闭的已有记录在下次打开时作为中断记录补传。联网恢复或空闲时补传失败记录；不确定状态先GET检查session是否已存在，避免回包丢失后重复提交。接口本身没有已核实的幂等键，多标签并发仍应避免。
